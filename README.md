🛒 Hina PRIME STORE

Hina PRIME STORE ek modern e-commerce style web application hai jo Daraz jesi UI design follow karti hai. Is platform par users apne products upload kar sakte hain aur dusre products browse kar sakte hain.

---

🚀 Features

- 🔍 Search bar (products easily find karne ke liye)
- 📂 Categories section (Daraz style scrolling)
- 📦 Product listing (grid layout)
- 📸 Product image upload system
- 💰 Price aur location display
- 🧾 Product description support
- 📱 Mobile responsive design
- 🧊 Clean & modern UI (Daraz inspired)

---

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

⚠️ Limitations

- ❌ Data permanently save nahi hota (refresh par delete ho jata hai)
- ❌ Cart system fully functional nahi hai
- ❌ Payment integration nahi hai
- ❌ Login/Signup system nahi hai

---

📈 Future Improvements

- 💾 Firebase database integration
- 🛒 Fully working cart system
- 💳 Easypaisa / JazzCash payment integration
- 👤 User authentication system
- ⭐ Product ratings & reviews

---

📌 Purpose

Is project ka main goal ek Daraz-style UI design aur basic marketplace system banana hai jo beginners ke liye helpful ho.
